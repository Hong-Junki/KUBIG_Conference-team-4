## 2. 핵심 발견 7가지

### 발견 ① 옛날 데이터 ACLED 결측 (2014-2017)

ACLED(분쟁 이벤트 데이터)는 자체 historical coverage 한계로 옛날엔 일부 국가만 기록되어 있습니다.

| 연도 | 58개국 중 데이터 있는 국가 |
|------|------|
| 2014 | **32개 (절반)** |
| 2015 | 35개 |
| 2016 | 42개 |
| 2017 | 45개 |
| 2018+ | 56~58개 (정상) |

**영향**: 데이터 없는 국가-연도 행은 ACLED 피처가 0으로 채워집니다. 모델이 "ACLED 0 = 평화"라고 잘못 학습할 위험이 있습니다.

**회의 안건 (결정 대기)**:
1. country별 ACLED 시작일 이전 행을 train에서 제외 (가장 깨끗, 단 train 행수 감소)
2. **ACLED 결측 마스크 컬럼 추가 (권장)** — train 행수 보존하면서 모델이 "0이 진짜 0인지, 데이터 없는지" 구분 가능
3. 그대로 진행 — y_escalation 양성비(4.29%)는 유지되므로 큰 영향 없을 수도

권장안: ②. 회의에서 합의 후 적용 예정.

GDELT(뉴스)는 12년 전 기간 58/58 풀커버이므로 영향 없습니다.

### 발견 ② 2014년 1월 양성률 spike (24%)

- 30일 rolling 평균 양성률이 2014-01-01에 0.2414 기록
- ①의 부작용 — 데이터 있는 32개국 중 분쟁국이 몰려있어 비율이 튐
- 학습 초반 노이즈 → train 시작일을 약간 늦추는 옵션도 검토 가능

### 발견 ③ 국가별 양성비 drift (train vs test)

| 방향 | 국가 |
|------|------|
| 양성 증가 | 차드, 예멘, 토고, 튀르키예, 과테말라 |
| 양성 감소 | 카메룬, **팔레스타인**, 마다가스카르, 사우디, 튀니지 |

**팔레스타인 특이사항**: 가자 사태(2023-10) 이후 만성 분쟁화. y_escalation은 "평시→급변"이므로, 늘 분쟁 중이면 escalation이 거의 안 잡힙니다. 백테스트 보고 시 모델이 PSE에서 underperform할 가능성을 명시해두는 게 좋습니다.

### 발견 ④ 일부 피처의 분포가 극단적

`skew > 5`인 피처가 11개. 대표:

| 피처 | skew (정상은 0~2) |
|------|------|
| acled_actor_type_5_ratio | **57** |
| acled_fatalities_max_7d | 11 |
| acled_event_count_30d | 8 |

**모델별 영향**:
- 트리 모델 (LightGBM, XGBoost): 그대로 사용 OK
- 선형 모델 (LogReg) / 시퀀스 모델 (LSTM): **log1p 변환 권장**

### 발견 ⑤ 단일 피처 신호가 매우 약함 (가장 중요한 발견)

각 피처 단독으로 "top 10% 그룹의 양성률 / 전체 평균 양성률" (lift) 계산:

| 1위 피처 | top 10% 양성률 | lift |
|---|---|---|
| acled_ratio_battles | 5.4% | **1.27배** |
| acled_actor_type_1_ratio | 5.3% | 1.24배 |
| acled_actor_type_7_ratio | 5.0% | 1.17배 |
| acled_ratio_vac | 5.0% | 1.16배 |
| acled_actor_type_8_ratio | 4.8% | 1.11배 |

**의미**:
- 어떤 단일 피처도 "이거 높으면 확실히 충돌"이라고 말하지 못합니다
- 모델은 **여러 피처 조합(interaction)** 으로 패턴을 잡아야 합니다
- 절대량(사상자 수, 이벤트 수)보다 **비율 피처(`ratio_*`, `actor_type_*_ratio`)** 가 신호가 강합니다 — 직관과 다른 결과
- 결론: **트리 기반 모델(LightGBM/XGBoost)** 이 자동으로 interaction을 학습하므로 본 환경에 강함

### 발견 ⑥ 피처 중복도 심각

`|상관계수| > 0.95`인 피처 쌍이 **23개**:

1. ACLED rolling 7d / 14d / 30d 거의 동일 (event_count 간 r=0.99, fatalities 간 r=0.97)
2. GDELT `mentions_sum` ≈ `event_count` (r=0.991)
3. GDELT 7d/14d/30d 윈도우도 0.97 이상

**모델별 대응**:
- LightGBM/XGBoost: 그대로 OK
- LogReg/LSTM: 윈도우 중 하나만 쓰거나 PCA 권장

### 발견 ⑦ 백테스트 케이스 사전 신호 (정성 확인)

`07_backtest_raw.png`에서 우크라이나/수단/가자 3케이스의 D-30~D+7 구간 raw 피처 시각화. D-day 직전(D-7~D-1)에 명확한 spike가 보이는지 사후 확인 필요. spike가 약하면 모델 한계로 명시할 예정.

## 3. 종합 결론

> **"불균형 + 옛날 데이터 결측 + 단일 신호 약함 + 피처 중복" 환경 → 트리 기반 모델(LightGBM/XGBoost)이 가장 강함.** 1.5년 데이터에서 LightGBM+SE가 1위였던 결과와 이론적으로 일치합니다.
