## 해석 주의사항

1. 채택 기준: C + 0.003 = 0.0683. 이를 초과하면 C2 피처 셋 채택.
2. B baseline(0.0564)과의 비교는 참고용. C(0.0653) 대비 개선이 핵심 기준.
3. Isotonic ECE ≈ 0은 val 과적합 (val 셋 크기 작음). Platt 채택.
4. test는 아직 평가하지 않았다. B/C/C2 비교 후 최종 모델 결정 시 1회 평가.
5. C2 피처는 C 피처 parquet를 재사용해 로컬 생성 (BigQuery 추가 비용 없음).

## C2 미채택 결론 및 분석

### 결론

**C2 feature set (C + 파생 19개, 총 76개) 는 최종 feature set으로 사용하지 않는다.**

- Stacking Platt PR-AUC: C 0.0653 → C2 0.0643 (**-0.0010 하락**)
- 채택 기준 0.0683에 **0.004 미달**
- C2 파생 19개를 전체 추가하는 방식은 스태킹 앙상블 기준으로 효과 없음

### 세부 관찰

- **LightGBM 단독**은 C2(0.0642) > C(0.0601)로 **+0.0041 개선**됨.  
  C2 파생 피처 중 일부는 LightGBM 트리에서 유효한 분기를 제공하는 것으로 보임.
- **XGBoost 단독**은 C2(0.0566) ≈ C(0.0546)로 소폭 개선에 그쳤고,  
  조기종료가 round 1에서 발생 → C2 피처가 XGBoost 기준으로는 노이즈로 작용했을 가능성.
- Meta learner(LogReg)가 LightGBM 쪽으로 거의 수렴(C=0.01)했음에도  
  전체 Stacking은 C 대비 하락 → 피처 증가에 따른 과적합 또는 rolling 피처의 look-ahead 미검증 필요.

### 후속 분석 옵션 (현재 미수행)

아래 분석을 통해 C2 피처 중 실제로 유효한 것만 선별할 수 있다:

1. **C2 feature importance 분석** — LightGBM gain/split importance로 19개 중 상위 피처 확인
2. **C2 feature correlation 분석** — 기존 C 피처와 높은 상관을 갖는 C2 피처는 중복 가능성
3. **Selected C2 ablation** — 상위 importance 피처 3~5개만 추가한 C+선별C2 실험

단, 위 분석은 현재 단계에서 우선순위가 낮다.  
**스태킹 기준 유의미한 개선을 위해서는 완전히 새로운 정보 소스가 필요하다.**
