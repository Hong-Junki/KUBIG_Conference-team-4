## D 미채택 결론 및 현재까지 최종 결론

### 결론

**D feature set (C + theme/person 22개, 총 79개) 은 최종 feature set으로 사용하지 않는다.**

- Stacking Platt PR-AUC: C 0.0653 → D 0.0633 (**-0.0020 하락**)
- C2(0.0643) 대비로도 -0.0010 하락 — D는 C2보다도 낮음
- 채택 기준 0.0683에 **0.005 미달**
- D 전체 22개 theme/person feature를 그대로 추가하는 방식은 스태킹 앙상블 기준 효과 없음

### 세부 관찰

- **LightGBM 단독**(0.0649)과 **XGBoost 단독**(0.0607)은 C 대비 모두 개선됨.  
  v2themes / v2persons 기반 피처가 개별 트리 모델에는 유용한 분기를 제공함.
- **Stacking 기준 하락 원인**: meta learner가 LightGBM에 과도하게 치우쳐(C=10),  
  XGBoost의 개선분이 앙상블에 반영되지 못했을 가능성.  
  또한 피처 수 증가(57→79)에 따른 OOF 과적합 위험도 배제할 수 없음.
